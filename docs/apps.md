# Apps and coding agents

This cookbook covers code. For apps and coding agents, the step-by-step guides are on the FreeTheAI site, where they stay current:

**[freetheai.org/setup](https://freetheai.org/setup)**

The setup pages give the base URL, the key, and the settings each app needs. You will need:

- your API key from [API keys](https://freetheai.org/dashboard/api-keys),
- the base URL `https://api.freetheai.org/v1`,
- a model ID such as `glm-5.3` from the [models list](https://freetheai.org/models),
- money in your wallet and a provider you follow ([freetheai.org/providers](https://freetheai.org/providers)).
