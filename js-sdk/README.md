# JavaScript SDK

The official client for Node.js 18 or newer, Bun, Deno, and browsers (keep keys on the server in browsers). Zero runtime dependencies.

```bash
cd js-sdk
npm install
FREETHEAI_API_KEY="ftai_..." npm start
```

The SDK docs are at [free-the-ai.github.io/freetheai-js](https://free-the-ai.github.io/freetheai-js/).
