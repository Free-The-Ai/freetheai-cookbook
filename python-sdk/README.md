# Python SDK

The official Python client. It adds the FreeTheAI behaviours you would otherwise write yourself: fallback models, a learned concurrency limit, retries for busy models, and clear errors for the daily check-in and the daily limit.

```bash
pip install freetheai
export FREETHEAI_API_KEY="ftai_..."
python example.py
```

The SDK docs are at [free-the-ai.github.io/freetheai-python](https://free-the-ai.github.io/freetheai-python/).
